# Firmware for AVR-based HBS86H stepper driver

AVR1284-based stepper controller used for interactive motion control (run in selected direction until the approaching end-position is encountered or the buttin get 
released). Also supports a keypad-based "semi-automatic", asynchronous operation mode where the operator can enter the desired distance position in steps or millimetres.

Based on aroncbds/avr-devenv-boilerplate.
